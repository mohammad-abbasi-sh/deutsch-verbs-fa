# Conjugation tables — German verbs (reference)

Endings are added to the **stem** (infinitive minus `-en`; `-eln`/`-ern`
verbs drop only `-n`: *lächeln → lächel-*, *wandern → wander-*).

## Präsens endings

| | weak / strong | example: lernen / gehen |
|---|---|---|
| ich | -e | lerne / gehe |
| du | -st | lernst / gehst |
| er/sie/es | -t | lernt / geht |
| wir | -en | lernen / gehen |
| ihr | -t | lernt / geht |
| sie/Sie | -en | lernen / gehen |

### -e- insertion (du / er / ihr)

A `-e-` is inserted before `-st`/`-t` when the stem ends in **-d / -t**
(*arbeiten → du arbeitest*, *finden → du findest*, *reden → du
redest*) or in **-m / -n after a consonant** (*atmen → du atmest*,
*rechnen → du rechnest*, *öffnen → du öffnest*). No insertion after
**l, r, m, n** or a vowel (*lernen → du lernst*, *kommen → du kommst*,
*stimmen → du stimmst*, *beginnen → du beginnst*), after single **h**
(*wohnen → du wohnst*, *nehmen → du nimmst* — but *rechnen → du
rechnest*, because `ch` counts as a consonant cluster).

**Exception:** strong verbs with a stem change do **not** insert the
`-e-` in du/er (*raten → du rätst*, *halten → du hältst*, *laden → du
lädst*), but ihr still takes it (*ihr ratet*, *ihr haltet*).

### -s stems

Stems ending in **-s / -ß / -x / -z** take only `-t` in du
(*reisen → du reist*, *heißen → du heißt*, *sitzen → du sitzt*,
*wachsen → du wächst*).

### Stem change (du / er only — never ich, wir, ihr, sie)

- **a → ä:** *fahren → du fährst*, *schlafen → du schläfst*,
  *laufen → du läufst*, *tragen → du trägst*
- **e → i:** *essen → du isst*, *geben → du gibst*,
  *nehmen → du nimmst* (note: `nehm-` → `nimm-`, not `*nihm-`),
  *sprechen → du sprichst*, *helfen → du hilfst*
- **e → ie:** *sehen → du siehst*, *lesen → du liest*,
  *stehlen → du stiehlst*, *empfehlen → du empfiehlst*

## Präteritum

| | weak | strong | mixed |
|---|---|---|---|
| ich | stem + -te | stem | stem + -te |
| du | stem + -test | stem + -st | stem + -test |
| er | stem + -te | stem | stem + -te |
| wir | stem + -ten | stem + -en | stem + -ten |
| ihr | stem + -tet | stem + -t | stem + -tet |
| sie | stem + -ten | stem + -en | stem + -ten |

Examples: *lernen → ich lernte*; *gehen → ich ging*; *wissen → ich
wusste*; *denken → ich dachte*; *bringen → ich brachte*.

**-e- insertion in strong Präteritum:** when the Präteritum stem ends
in **-d / -t / -s / -ß / -x / -z**, insert `-e-` before du `-st` and ihr
`-t`: *finden → du fandest, ihr fandet*; *lesen → du lasest, ihr
laset*; *bitten → du batest*; *sitzen → du saßest*; *vergessen → du
vergaßest*. Otherwise no insertion: *gehen → du gingst*,
*kommen → du kamst*, *sehen → du sahst*.

## Partizip II

| | form | example |
|---|---|---|
| weak | ge- + stem + -t | *gelernt*, *gearbeitet* |
| strong | ge- + stem + -en | *gegangen*, *gesehen*, *gegessen* |
| mixed | ge- + stem + -t | *gewusst*, *gedacht*, *gebracht* |
| -ieren verbs | stem + -t (no ge-) | *studiert*, *telefoniert* |
| inseparable prefix | prefix + stem + -t/-en (no ge-) | *besucht*, *verstanden*, *vergessen* |
| separable prefix | prefix + ge- + stem + -t/-en | *angekommen*, *aufgestanden*, *eingekauft* |

The `-e-` insertion rule applies inside Partizip II too
(*gearbeitet*, *geöffnet*).

## Perfekt

`haben`/`sein` in Präsens + Partizip II: *ich habe gelernt*,
*ich bin gegangen*. See `tense-guide.md` for haben vs. sein.

## Futur I

`werden` in Präsens + infinitive: *ich werde gehen*,
*du wirst lernen*.

## Konjunktiv II

| | weak | strong | mixed |
|---|---|---|---|
| ich | = Präteritum | umlaut stem + -e | umlaut stem |
| du | = Präteritum | umlaut stem + -est | umlaut stem + -st |
| er | = Präteritum | umlaut stem + -e | umlaut stem |
| wir | = Präteritum | umlaut stem + -en | umlaut stem + -n |
| ihr | = Präteritum | umlaut stem + -et | umlaut stem + -t |
| sie | = Präteritum | umlaut stem + -en | umlaut stem + -n |

Examples: *gehen → ich ginge*; *fahren → ich führe*;
*kommen → ich käme*; *sein → ich wäre*; *haben → ich hätte*;
*werden → ich würde*; *können → ich könnte*; *wissen → ich wüsste*;
*denken → ich dächte*. Note: *senden → ich sendete* and
*wenden → ich wendete* (not *sändte* / *wändte*).

Weak verbs: Konjunktiv II **is** the Präteritum (*ich lernte*); in
speech the polite form is usually *würde + Infinitiv*
(*ich würde lernen*).

## Imperativ

| | form | example |
|---|---|---|
| du | stem (+ -e after -d/-t, -m/-n after consonant, -ig, -nn) | *lern!*, *arbeite!*, *finde!*, *beginne!* |
| ihr | = ihr Präsens | *lernt!*, *geht!*, *ratet!* |
| Sie | infinitive + Sie | *lernen Sie!*, *gehen Sie!* |

**Stem change in Imperativ du:** `e → i` / `e → ie` apply
(*iss!*, *lies!*, *sieh!*, *gib!*, *nimm!*, *sprich!*), but
`a → ä` does **not** (*fahr!*, *lauf!*, *trag!*, *schlag!* —
never `*fähr!`).

**Separable verbs:** the prefix goes to the end
(*komm an!*, *kommt an!*, *kommen Sie an!*).

**Modal verbs** (*können, müssen, wollen, sollen, dürfen, mögen*)
have no usable imperative — the tool reports that instead of
inventing one.
